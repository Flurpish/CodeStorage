# What is Programming?

## Introduction

Welcome to the wide (and sometimes miserable) world of programming! By going through this repository, you should be able to piece topics together in a way that makes learning easier. I will try to organize everything so that each topic builds on the last.

## Programming Definition

Programming is the process of creating instructions that a computer can execute to perform tasks, solve problems, or automate actions.

A more formal definition would be:

> Programming is the process of designing, writing, testing, and maintaining instructions that enable a computer to perform specific tasks.

It does not always have to sound that advanced, though. At its core, programming is simply telling a computer what to do.

A **program** is the actual set of instructions written for a computer to execute. In other words, **programming** is the process, while a **program** is the result.

## Why Programming Exists

Programming exists because humans needed a way to communicate instructions to computers. Computers are powerful machines, but they do not think for themselves. They only follow the instructions they are given (yes this is technically true for AI).

These instructions are written in **programming languages**. In this repository, I will mainly use **Python**, but there are many different languages used in computer science and software development, such as **C**, **C++**, **Java**, and **Python**. You may also come across languages like **SQL** and **HTML**, although they serve different purposes from general-purpose programming languages.

While the number of languages may seem intimidating, many of them share similar ideas. Most programming languages include the same core concepts. The main differences are usually in speed, level of control, and what kinds of tasks they are best suited for. Not to mention how they're written.

For example, **C++** gives programmers much more low-level control over memory and hardware, which makes it useful for systems programming (like Windows and Linux). **Python**, on the other hand, is easier to read and write, which makes it very popular for beginners.

You do not need to master every language. Once you understand the core ideas of programming, learning a new language becomes much easier.
